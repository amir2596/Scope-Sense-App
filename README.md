# ScopeSense — Flutter Client

A minimal Flutter client for the Go pricing/RAG API (`cmd/api`). It has two
screens:

- **Input screen** — enter a client's (Persian) project description and their
  stated budget, plus the API's base URL.
- **Result screen** — shows the verdict (realistic / underpriced /
  overpriced / no data), the price range from comparable projects, the
  structured spec extracted by the clarifier agent, the comparable projects
  themselves, and the written Persian explanation.

## Setup

This zip contains only the Dart source (`lib/`) and `pubspec.yaml` — not a
full Flutter project scaffold (no `android/`, `ios/`, `web/` folders), since
those are generated by the Flutter SDK itself and weren't buildable in the
environment that produced this code.

1. Create a fresh Flutter project and copy these files in:
   ```bash
   flutter create scopesense_client
   cd scopesense_client
   # replace the generated lib/ and pubspec.yaml with the ones from this zip
   flutter pub get
   ```
2. Run it:
   ```bash
   flutter run
   ```

## Connecting to your Go server

The default base URL in the app is `http://10.0.2.2:8080`, which is the
Android emulator's alias for your machine's `localhost:8080` (where
`cmd/api` listens by default). Change it in the "Server settings" expander
on the input screen if you're:

- running on a physical device (use your machine's LAN IP instead),
- running on iOS simulator (`localhost:8080` works directly there), or
- pointing at a deployed server instead of a local one.

## Notes

- The server's `evaluateTimeout` is 30s; the client's request timeout is
  35s, so the server's own timeout error should generally surface first.
- If your vector search finds no comparable projects (`verdict: "no_data"`),
  the result screen still renders — it just shows an empty comparables list
  and no price range.
- No state-management package is used (plain `StatefulWidget`/`setState`);
  swap in Provider/Riverpod/Bloc if you'd rather match a pattern you already
  use elsewhere.
